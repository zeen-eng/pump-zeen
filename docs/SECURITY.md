# الأمان في pump.zeen

لا يوجد موقع «غير قابل للاختراق»، لكن هذا التصميم يغلق الطرق الشائعة ويضع الحماية حيث لا يستطيع المهاجم تجاوزها: **في الخادم**، لا في المتصفح.

| الخطر | الحماية | أين |
|---|---|---|
| مستخدم يقرأ أو يعدّل تصاميم غيره | Row Level Security: كل صف مربوط بمالكه، والمالك يُفرض في Trigger ولا يُقبل من المتصفح | `001_init.sql` |
| مستخدم يرفع نفسه إلى مدير | عمود `role` غير قابل للتعديل من المتصفح (صلاحية العمود محجوبة)، والتغيير فقط عبر دالة تتحقق أن الطالب مدير | `001_init.sql` |
| فتح لوحة الإدارة | كل دالة إدارية تبدأ بـ `assert_admin()`؛ الصفحة نفسها لا تحمل بيانات. واختيارياً Cloudflare Access أمامها | `001_init.sql`, `DEPLOY.md §5` |
| حقن سكربت (XSS) | سياسة CSP تمنع أي سكربت غير ملفات الموقع نفسه (لا inline، لا مصادر خارجية)؛ كل نص من المستخدم يُعرض بـ `textContent` أو `esc()` | `_headers`, `core/dom.js` |
| حقن SQL | لا يوجد SQL في المتصفح؛ الاستعلامات عبر PostgREST بمعاملات، والدوال `security definer` بـ `search_path = ''` | `auth/supabase.js`, `001_init.sql` |
| بيانات تصميم مُتلاعب بها | `cleanDesign()` يعيد بناء التصميم من الحقول المعروفة فقط ويحصر كل رقم في حدوده. وقاعدة البيانات تحد حجم التصميم (64KB) وعددها (200 لكل مستخدم) | `core/sanitize.js`, `001_init.sql` |
| تخمين كلمات المرور | حدود معدّل Supabase Auth + قفل مؤقت في الواجهة بعد 5 محاولات + كلمات مرور 10 أحرف على الأقل | Supabase, `pages/login.js` |
| كشف وجود حساب من «نسيت كلمة المرور» | نفس الرد دائماً سواء كان البريد مسجلاً أم لا | `pages/login.js` |
| سرقة الجلسة | رمز الدخول في الذاكرة فقط، ورمز التجديد في `sessionStorage` (يُمسح بإغلاق التبويب)، والخروج يُبطل الجلسة في الخادم، وإغلاق تلقائي بعد 20 دقيقة خمول | `auth/supabase.js`, `auth/index.js` |
| تضمين الموقع في إطار (Clickjacking) | `X-Frame-Options: DENY` و`frame-ancestors 'none'` | `_headers` |
| التنصت | HTTPS إجباري + HSTS سنتين | `_headers`, Cloudflare |
| تسريب الرابط لمواقع أخرى | `Referrer-Policy: no-referrer` | `_headers` |
| رمز الاستعادة في سجل المتصفح | يُزال من شريط العنوان فور فتح الصفحة | `pages/reset.js` |
| مكتبات خارجية مخترقة (Supply chain) | لا توجد مكتبات JavaScript خارجية إطلاقاً؛ الخط فقط من Google Fonts (CSS، لا سكربت) | — |
| تسجيلات مزعجة | زر إغلاق التسجيل في لوحة الإدارة يُنفَّذ في الخادم (Trigger يرفض المستخدم الجديد) | `001_init.sql` |

## ما يبقى عليك

1. **لا تنشر مفتاح `service_role` أبداً**، ولا كلمة مرور قاعدة البيانات.
2. فعّل **التحقق بخطوتين (2FA)** على حساباتك في GitHub وCloudflare وSupabase. من يملك هذه الحسابات يملك الموقع.
3. فعّل **Confirm email** في Supabase.
4. افحص **Supabase → Advisors → Security** بعد أي تعديل على قاعدة البيانات.
5. عند إضافة جدول جديد: `enable row level security` وسياسة صريحة، دائماً.
